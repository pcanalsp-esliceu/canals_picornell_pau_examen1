EXERCICI A2 · 💻 EL MENÚ, AMB CAIXES CLICABLES
Ara el menú és una llista amb pics, i només pots clicar damunt de les lletres. Afegeix això al teu
css/estils.css :
nav ul {
    list-style: none; /* fora els pics */
    margin: 0;
    padding: 0; /* fora el sagnat de la llista */
}
nav a {
    display: block; /* l'enllaç passa a ser una caixa */
    padding: 10px 16px;
}

Prova-ho: ara pots clicar a qualsevol lloc de la franja, no només damunt del text. Esborra el display:
block i torna-ho a provar.
Per què hem posat display: block a l’enllaç i no l’hem deixat com estava?

Perque no es sobrelapin un amb l'altra
